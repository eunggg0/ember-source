# Ember — open-source component source / 오픈소스 구성요소 소스

Complete corresponding source for the LGPL / MPL components bundled in **Ember 1.0** (Wine, DXMT, GStreamer, GLib,
FFmpeg, GnuTLS, wine-gecko, …), Ember's patches to them, and the build configuration.

Ember 의 수정 패치, 빌드 설정입니다.
